# Idris — личная страница

Моя первая страница на чистом HTML, CSS и JavaScript.
Опубликована через GitHub Pages.

## Структура

- `index.html` — разметка страницы
- `styles.css` — стили (тёмная и светлая темы)
- `script.js` — переключатель темы, год в футере

## Запуск локально

Открыть `index.html` в браузере. Сборка не нужна.
